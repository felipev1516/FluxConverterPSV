- Change default txt and log rename format:
	- The default text file extentions was following a previous ATVI project curriculum so need to change to a neutral format.
	- Old txt format: dxdiag_(PROJECT)_BUG#_PROJECT#_ATVICOMPUTER#_BRANCH_BUILD#_
	- New txt format: ATVIQA_PROJECT-BUG#_BUILD#
	- Old Log Format: ATVIQA_PROJECT-BUG#_BUILD#_
	- New Log Format: ATVIQA_PROJECT-BUG#_BUILD#
	- Old INI format: ini_PROJECT-BUG#_BUILD#_
	- New INI format: ATVIQA_PROJECT-BUG#_BUILD#
	- Old CFG format: Config_DEVICE_PROJECT_BUG#_BUILD#_
	- New CFG format: ATVIQA_PROJECT-BUG#_BUILD#
- Added .config file support:
	- CONFIG format: ATVIQA_PROJECT-BUG#_BUILD#
